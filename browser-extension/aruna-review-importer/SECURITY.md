# Segurança

- Pareamento por código temporário de 8 caracteres com validade curta.
- Após o pareamento, é emitido token longo e aleatório; no servidor fica somente o hash.
- O token pode ser revogado no Aruna Review.
- Lotes importados entram na caixa de entrada e seguem moderação.
- Não há service role, senha Shopify ou credencial BK dentro da extensão.
