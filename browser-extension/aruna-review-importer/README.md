# Aruna Review Importer

Extensão clean-room para enviar avaliações públicas autorizadas ao Aruna Review, sem login BK e sem depender da infraestrutura do BK.

## Conexão
1. Abra **Aruna Review** no Admin da Shopify.
2. Na área **Importador Aruna**, clique em **Gerar código de conexão**.
3. Abra a extensão e digite o código de 8 caracteres.
4. Escolha o produto de destino da Shopify.
5. Abra a página pública do produto/marketplace, clique em **Ler página aberta** e revise a prévia.
6. Clique em **Enviar para Aruna Review**.
7. O lote entra na caixa de entrada e é sincronizado para moderação no painel.

A extensão marca os registros extraídos como importados e não os marca como compra verificada.
