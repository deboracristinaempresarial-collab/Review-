# Instalação manual

1. Baixe/extraia a pasta `aruna-review-importer`.
2. Abra `chrome://extensions` no Chrome/Quetta compatível.
3. Ative o modo do desenvolvedor.
4. Escolha **Carregar sem compactação** e selecione a pasta da extensão.
5. Faça o pareamento pelo código gerado dentro do Aruna Review na Shopify.
